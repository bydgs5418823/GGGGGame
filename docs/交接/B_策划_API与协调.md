# B 的交接文档与统一交付总表 v0.3

更新日期为 2026-11-10。B 继续负责统一策划、属性与 API 发布、素材派单和验收。本次只同步车型与人数、实体手册、定速巡航、负重跳跃及相关空间验证，原人员分工沿用。

## 1. B 本轮接收的明确要求

正式游戏支持 1～4 人，单人可完成基本送货，多人自由安排驾驶、装卸和押货。后舱规划最多 3 人作业，空车验证 4 人基本活动，六货装载后验证 3 人活动和避让。开局通过简单提示引导阅读出生区的一本实体手册，设置提供按键查看与修改。封闭式客货车、平稳行驶后舱活动、定速巡航和按货物重量区别跳跃均按灰盒 v0.3 验收。常态第一人称和同对象多人作用保留。

B 把人物、场景、物理、镜头、素材和 API 要求集中到统一版本中下发。成员交回实现与实测，B 再汇总修订。

本版采用的具体数值、首轮分派和制作规格为评审初稿，用户已确认的方向见[灰盒设计](../灰盒设计_v0.1.md)第 1 节。

## 8. B 需要统一决定的技术与产品问题

1. 当前工程作为正式游戏原型还是独立实验场。
2. 新车轴距、轮距、轮半径与空车质量，座位及后舱活动人员的唯一质量贡献；原翻车与救车边界继续待定。
3. 权威物理端承载方式、网络传输与测试框架，具体工具链版本。
4. 行驶中后舱基本活动已确认，验证其稳定性和大型货物彻底重固条件；人物伤害等高级机制沿用原待定状态。
5. 特定地点第三人称白名单，以及本版素材预算在实测后的修订。

这些问题由 B 汇总备选、技术影响和实测结果，涉及核心方向时提交项目发起人选择。1～4 人自由分工、单人基本送货、常态第一人称、实体手册和同对象多人作用作为当前验收依据。
