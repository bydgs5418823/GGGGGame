# D 的人物作业功能交接单 v0.3

更新日期为 2026-11-10。D 的人物作业与协作搬运分工保留。本次同步实体手册、设置按键、负重跳跃、新车舱内通行及 1～4 人正式目标，五条工作线继续沿用。

## 1. B 已下发的完整功能

交付在实际送货场景可操作的人物作业包。正式支持 1～4 人，一人即可开始并完成基本流程。玩家按出生区提示接近实体手册阅读，以第一人称活动、搬运和自由安排职责，同对象共同抓取保留。进入驾驶位启用第三人称，回到步行恢复第一人称。平稳行驶允许后舱自由活动。

本单采用[灰盒设计 v0.3](../灰盒设计_v0.1.md)。[独立 API v0.2](../API与联调契约_v0.2.md)本次保持原稿，实体阅读、按键设置、负重跳跃及人数等差异由 B 登记待同步，冲突语义以灰盒 v0.3 为当前设计。D 回交范围沿用原功能。

## 5. 同对象多人作用的实现约束

1. 每件货物维护参与者集合，P2 加入时保留 P1，离开仅移除对应玩家。
2. 每人的局部抓点、世界目标和输入序号分别保存，单独计算和限幅。
3. 原 35 kg/人支持能力、650 N 抱持及 450 N 拖拽仅作待验种子，按单人完成标准货物装卸复核；多人提高效率，每物两人样本与整局最多四人分开处理。
4. 每个更新向 E 提交对应 ForceContribution，合力与力矩由同一个物理结果处理。
5. 相同玩家同一输入重传进行去重，不同玩家的有效输入都参与。
6. 进入座位前需要空手。UI 打开或失去焦点时发送中性移动，清理按既定规则处理。
7. 靠近实体手册且空手时交互阅读，阅读界面只消费本地输入，同一本物件支持多位读者并发。驾驶与搬运通过设置查看按键。
8. 相机是本地呈现，参与关系、物体与人物共享状态由确认结果决定。
9. 20 kg 木箱允许较低高度携物跳跃；拖 60/150 kg 物体时先清理跳跃者本人的抓取再空手起跳，其他人的关联继续，重物不获得人物跳跃分量。多人协同跳跃复杂规则留待后续。
10. 后舱步行保持 OnFoot，平稳行驶可相对地板移动，不以座位占用表示全部乘员。急刹急转和碰撞的基本稳定性由 D/E 联调，暂不扩展高级平衡系统。

### 本轮同步的测试与审查要求

- 原移动、蹲姿、空中重复跳跃及上下文镜头检查继续保留。
- 空手正常跳跃，20 kg 木箱保持抓取且较低离地；60/150 kg 仅释放本人后人物起跳，货物不获跳跃冲量。

- 设置可查看和修改基本操作绑定，行为与手册各自显示保持一致，取消和冲突提示可用。
- 新车隔断门 0.8 × 1.9 m 和后门 1.6 × 2.0 m 按实际人体碰撞验证，空车 4 人、六货加 3 人分别检查。
- 两人处理重物时第三人可通行和避让，正常平稳行驶可在后舱活动，危险工况观察基本失稳反馈。
- 1、2、3、4 人各有完整核心流程，标准货物操作存在单人方案；原双人同物体输入、松手、断线、重置和旧请求检查继续保留。
- 技术审查核对独立 API 的待同步项，防止原自动手册、空手才可跳或座位限定后舱活动等语义残留。
