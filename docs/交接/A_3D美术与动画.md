# A 的具体交接单 v0.3

更新日期为 2026-11-10。B 下发本轮美术和动画制作内容，A 的职责沿用原分工。本次同步新车型、1～4 人空间、实体手册与轻箱跳跃基础表现，优先使用简单几何体和占位资源。

## 1. 接收的任务

制作清单现为 11 项模型或场地资源，新增实体手册并替换车辆结构。原有 10 动作清单继续保留，轻箱跳跃用占位姿态或现有动作表现，本次不增加精细模型和额外动画资源任务。交付仍包含源文件、简化碰撞代理和导入预览。

B 的规格已列于[统一交付总表](B_策划_API与协调.md)第 3 节。人物、货物和车辆用途、数值、相机规则采用[灰盒设计](../灰盒设计_v0.1.md)。本轮尺寸、技术预算和动作时长属于 B 的可调整初稿。

B 负责玩法用途、尺度、状态、挂点和对外控制要求的统一发布。A 按本文制作，遇到可制作性和表现问题向 B 提交具体差异。程序接入人按本轮功能单确定为人物 D、车辆和场地 E、货物 D/E。

## 3. 已给定的模型技术属性

| 属性 | 本轮要求 |

| 地面和直路原点 | 模块上表面中心，便于拼接 |
| 材质 | player_gray、vehicle_gray、wood、metal、heavy_metal、concrete、region_load、region_delivery 作为语义名称 |
| 可读性 | 区分角色朝向、驾驶区、实体隔断门、后舱、后门、车轮、货物类别及实体手册 |

| 模型初稿预算 | 角色原 5000、车辆原 8000、货物原 1000、场地原 500 三角形作为待验成本参考；新车与手册优先原语占位，精细度不是本轮验收前提 |
| 材质初稿预算 | 每个角色或车辆最多 3 个材质槽，货物和场地单项优先 1 个 |

| 动画采样 | 30 fps，原地动作，位移由程序控制 |

以上预算属于灰盒制作初值。首样发现不合理时向 B 提交对应资源、实际成本和改法，B 一次性修订影响的制作单。

## 4. 具体节点和挂点

### 4.1 人物

人物模型分出 Head、Body、Hands 等可按本地视角控制可见性的部件，骨架为同一套。提供 HandGripLeft、HandGripRight、EyeStanding、EyeCrouching。

EyeStanding 高度 1.62 m，EyeCrouching 高度 1.02 m，相对于人物脚底。手部点随骨骼运动，D 将其映射到第一人称交互表现。人物的物理抓取点保存在货物上，手部模型跟随该表现。

### 4.2 封闭式客货混合运输车

整体参考大巴内部布局，外观体现货运。后舱清空乘客座椅，供货物与人员活动。驾驶区通过实体隔断门与后舱连通，后部设装卸门。

| 节点或结构 | 暂定规格与位置要求 | 用途 |
|---|---|---|
| BodyShell / Cabin | 外形 6.8 × 2.4 × 2.9 m，驾驶区长约 1.8 m | 外轮廓和前部驾驶区占位 |
| CargoBed / CargoInteriorBounds | 净长 3.8、净宽 2.1、净高 2.2 m，地板距地约 0.7 m | 后舱净空、载物与人员空间 |
| CabinPartition / PartitionDoor | 实体隔断，净门洞宽 0.8、高 1.9 m | 单人正常通行，门框和开启门扇另行检查 |
| RearDoor / RearEntry | 净开口宽 1.6、高 2.0 m | 人员及标准货物装卸 |
| 地面接驳占位 | 后舱地板到地面的连续装卸路径待验证，可用简单连接几何体检查 | 单人重物装卸可达性 |
| WheelFL/FR/RL/RR | 轴距、轮距、轮胎半径和轮心位置待新车型验证 | 保留独立轮节点，不沿用旧车坐标作为采用值 |
| SeatDriver / SeatPassenger | 在驾驶区内按人体占位复核，driver 保留，既有前部乘员占位按几何检查 | 驾驶与可选前部乘坐，均计入最多 4 人 |
| ExitLeft / ExitRight / 内舱通路 | 舱外安全落点及前后舱连通路径分别检查 | 座位离开、步行通行和装卸 |
| CameraDriveTarget | 按新车外包围与驾驶视线复核 | D 的第三人称焦点 |
| AudioEngine / AudioListenerDriver | 沿用语义节点名，位置按新车驾驶区复核 | 对应 C 的现有播放属性 |
| AudioTireFL/FR/RL/RR | 对应新轮位，具体坐标待验 | 轮胎声音位置 |

后舱应提供地板、内壁、顶棚、门框与门扇的简化几何。门洞以实际可通行净空测量，轮罩和门扇侵占须可观察。

外高 2.9 m 与地板 0.7 m、净高 2.2 m 相加无顶棚厚度余量，这组尺寸尚未成立为最终实体结构。A 保留净空框和外轮廓作对照，把冲突交 B 汇总，调整取值后再锁定模型。

后舱容量验收分别为，空车最多 4 人基本活动，以及合理装入 6 件货物后 3 人活动、两人处理重物时第三人通行避让。人数是容量验证条件，正式游戏按实际 1～4 人自由分工。

### 4.3 货物与场地

每件货物提供底面、几何中心和左右 GripHint 标记，供视觉提示和对照测量。实际多人抓取允许在有效命中表面建立独立局部抓点。

地面、直路和弯道边界清楚。区域标记使用独立显示材质，路面高度与接缝在拼接示例中核对。初始场地总尺寸约 60 × 40 m，由 E 组装。

## 5. 10 个动作的具体交付

| 动作名 | 时长初稿 | 循环 | 驱动与可见行为 |
|---|---|---|---|
| idle | 1.0 s | 是 | 正常站立，朝向清楚 |
| walk | 1.0 s | 是 | 步行，D 按实际移动速度调整播放 |
| run | 0.75 s | 是 | 冲刺状态 |
| crouch_idle | 1.0 s | 是 | 降低身体并保持蹲姿 |
| crouch_walk | 1.2 s | 是 | 蹲姿移动 |
| carry_idle | 1.0 s | 是 | 抓持或共同施力的静态姿态 |
| carry_walk | 1.0 s | 是 | 抓持状态下移动 |
| seated | 1.0 s | 是 | 座位占用姿态 |
| grab | 0.35 s | 否 | 成功加入抓取后短动作 |
| release | 0.30 s | 否 | 松手后的短动作 |

grab 和 release 的视觉动作由确认事件触发，物理关系按确认状态更新。轻箱跳跃只需基础携箱姿态与人物/货物共同离地的占位表现，具体高度由 D/E 按新规则验证。沿用原动作检查，不新增专门跳跃片段或高级动画制作要求。

## 7. A 交回 B 的明确成果

1. 按 11 项资源清单交付源文件或灰盒占位制作记录，原人物 10 动作任务保持既有安排。
2. 对应导出文件保留节点和挂点，新车和实体手册允许以简单几何占位完成本轮比例验证。
3. 一份制作实测表，逐项记录尺寸、成本、材质、动画实际时长和源文件版本。
4. 首样与补齐批次的导入预览及问题修复记录。
5. 如提供模型或动画相关轻度算法，附本轮功能要求、输入输出、调用样例和可复现实例，由 B 纳入接口版本。

B 接收后统一更新交付状态。新车型尺寸与空间容量仍需验证，模型或占位本身不能作为容量达标证据。
