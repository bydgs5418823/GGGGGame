## 2. 首轮玩法和角色

### 2.1 一局灰盒的具体内容

1～4 名玩家进入同一送货场景，出生区提示引导玩家接近实体操作手册并按交互键阅读。玩家把 6 件标准货物装入封闭式运输车，自行安排装卸、驾驶和押货。独自游玩时由同一人依次完成各环节，多人时可同时协作或轮换职责。车辆经过平路、左右弯和低缓凸起到达卸货区，完成 6 件交付后显示完成提示，可重置并改变装载方案。

一名玩家即可开始和完成运输。满员时可以采用一人驾驶、其余人在后舱活动的组合，前后舱人数随实际任务变化。每件标准货物都应有单人可完成的基本搬运路径，协作增加效率与控制能力。

6 件货物包括 3 个木箱、2 个圆桶、1 个重物。场景同时承担实际送货和对照测试，操作手册在该场景内打开。

### 2.2 各对象的用途

| 对象 | 灰盒中的实际作用 |
|---|---|
| 1～4 名玩家 | 自由安排移动、阅读、搬运、共同施力、驾驶、押货和卸货，人数上限为 4 |
| 实体操作手册 | 出生区放置一本，靠近交互阅读，多人各有本地阅读界面与页码，按键显示跟随各自绑定 |
| 封闭式客货混合运输车 | 前部驾驶区，带门隔断连接可步入后舱，后部装卸入口，后舱清空乘客座椅并容纳货物与人员 |
| 木箱 | 单人搬运和堆放的基础样本 |
| 圆桶 | 单人拖动、双人辅助抬起及滚动样本 |
| 重物 | 单人可慢速推动或拖行装卸，双人可更高效地共同调整姿态，验证偏载影响 |
| 固定操作 | 快速改变货物与车厢的固定关系，保留载重影响 |
| 装载区与路线 | 装货、驾驶、平稳运输、风险与修正的连续空间 |
| 卸货区 | 判断已卸下货物并按实例计数 |
| HUD | 显示操作目标、参与者、固定状态、交付进度和驾驶信息 |
| 调试面板 | 切换试验预置、观测参数、保存记录和重置 |

### 2.3 局内流程

| 阶段 | 进入条件 | 规则与离开条件 |
|---|---|---|
| 准备 | 1～4 名玩家按实际人数生成 | 出生区显示“前往阅读操作手册”的简单提示，靠近实体手册按 E 阅读，关闭后继续；可以由一名玩家开始送货 |
| 装载 | 货车、货物生成完成 | 玩家可任意安排装货，驾驶员起步后记为运输阶段 |
| 运输 | 车辆行驶 | 玩家自行驾驶或在后舱押货。平稳行驶允许活动和基本货物操作，大型货物彻底重新固定受稳定条件约束 |
| 卸货 | 车辆到达卸货区 | 玩家卸下货物，按第 8 节条件计入交付 |
| 完成 | 6 件货物均计入交付 | 显示本轮用时、交付数及重置入口，玩家仍可观察场景 |
| 重置 | 调试或完成界面发出重置请求 | 增加回合编号，恢复人、车、货物和计数，清理上一轮关联 |

## 3. 操作与开局手册

### 3.1 输入动作表

以下保留简单键鼠驾驶。初始绑定可在设置菜单查看和修改，动作名作为统一引用，手册和 HUD 显示当前绑定。

| 动作名 | 初始绑定 | 步行或搬运 | 驾驶 |
|---|---|---|---|
| move | WASD | 视线水平朝向下移动，斜向速度归一化 | W 油门，S 制动并在低速时倒车，A/D 转向 |
| look | 鼠标移动 | 观察，俯仰受限 | 观察车辆周围，保持驾驶第三人称 |
| sprint | 左 Shift | 空手冲刺，携物时保持携物速度 | 无额外加速动作 |
| crouch | 左 Ctrl 按住 | 蹲下，受阻时保持蹲姿 | 无对应操作 |
| jump | Space 按下 | 按第 4.2 节的重量规则跳跃 | 手刹，并即时取消巡航 |
| interact | E 按下 | 货物抓取或松手、实体手册阅读、隔断门及装卸门交互、进入座位 | 满足低速及安全落点条件时退出座位 |
| rotate_held | 鼠标右键按住并移动 | 调整抓持目标朝向，暂停鼠标转动视线 | 无对应操作 |
| adjust_hold | 鼠标滚轮 | 调整抓持目标距离 | 在安全范围内调整观察距离 |
| secure | F 按下 | 扶持后的临时固定及完整固定请求，按第 6.3 节判断条件 | 无对应操作 |
| cruise_toggle | C 按下 | 无对应操作 | 开启或关闭定速巡航 |
| menu_back | Esc | 关闭阅读界面，或打开菜单并进入设置/按键绑定 | 同左，世界模拟持续运行 |
| debug_reset | 调试面板按钮 | 请求本轮重置 | 同左 |

抓持时 E 优先松手，空手时按视线命中对象尝试阅读、开关门、抓取或进入座位。实体手册的阅读与搬货分属不同交互目标，目标不满足条件时显示原因。

### 3.2 实体手册与设置

出生区域显眼台面放置一本实体操作手册，灰盒暂以固定摆放的薄盒与封面标记表示。开局提示“前往操作手册，按交互键阅读”。玩家需要接近、看向并按 E 打开本地界面，Esc 关闭。阅读保持世界模拟，输入仅由该玩家的阅读界面消费。

同一本手册允许 1～4 人同时阅读，每人独立翻页、关闭和显示按键，不设置独占阅读占用。出生和回合重置保留世界中的手册，生成玩家时显示引导提示。正常搬运和驾驶通过设置菜单查按键，完整手册需回到实体物件交互。

Esc 菜单提供设置入口及基本操作绑定列表，可查看、修改并保存绑定。同一输入上下文的冲突给出提示，取消修改保留原绑定。手册在打开或绑定变化时读取当前绑定，WASD、E、F、C 等文字均作为默认键的展示例子。

### 3.3 四页手册正文

正文由 B 维护，D 将键名替换为当前本地绑定。

#### 第 1 页 到岗与基本操作

欢迎加入送货队。用 WASD 移动、鼠标观察，左 Shift 冲刺、左 Ctrl 蹲下、Space 跳跃。准星对准货物后按 E 抓取，再按 E 松手。滚轮调整距离，按住鼠标右键移动可调整朝向。20 kg 木箱可以携带跳跃，高度会降低；拖动圆桶或重物时跳跃会先松开自己的抓取，货物保持原有物理运动。

#### 第 2 页 按人数安排工作

独自游玩可以依次装货、驾驶和卸货。队友加入后可自由分工和轮换。重货物可以缓慢推、拖，邀请队友加入可提高效率。两人对同一货物按 E 后各自作用都会生效，一人松手只移除自己的作用。让通道保持畅通，给其他人保留避让位置。

#### 第 3 页 装货、通行与驾驶

封闭运输车的驾驶区与后舱由带门隔断连接，后部入口用于装卸。把重货物放低、合理分布，按 F 请求固定或解除固定。正常平稳行驶时后舱可以活动、扶持、推动和调整货物，急刹、急转和剧烈颠簸会使人和货物失稳。大型货物彻底重新固定需要停车或低速、稳定条件。

对准驾驶位按 E 进入，镜头切到第三人称。W 油门，S 制动并在低速时倒车，A/D 转向，Space 手刹。达到希望保持的前进速度后按 C 开巡航，松开 W 后车辆仍尝试保持速度。巡航期间 W 不加速，方向仍由你控制。再按 C 关闭巡航，松开油门时自然滑行。按 S 或 Space 会立即取消巡航并制动。

#### 第 4 页 交付与查看按键

到卸货区后解除固定，把货物搬下放稳，所有玩家看到相同交付数量。操作无需凑齐四人，协作能提高效率。忘记按键时从 Esc 菜单进入设置查看或修改，需要完整说明可回到出生区手册阅读。调试版可在面板重置本轮。

### 3.4 本轮阅读与跳跃处理提案

固定摆放的手册外观与重物跳跃时先释放本人抓取，是本版的简单灰盒处理提案。人物打开阅读前需空手；界面打开时发送中性移动输入，重力、接触和其他玩家继续更新。复杂教程、随身阅读界面和多人协同跳跃系统留在本轮范围之外。

## 4. 人物完整属性与行为

以下数值为 B 的灰盒初始值，单位和默认行为属于本版接口语义。

### 4.1 身份、身体与生成

| 字段 | 初始值或规则 |
|---|---|
| player_id | 会话内稳定的无符号 64 位标识，连接映射由会话层维护 |
| display_name | 使用连接时提供的昵称，默认名按玩家 1 至玩家 4 分配 |
| body_height_m | 站立 1.8，蹲姿 1.2 |
| body_radius_m | 0.3，身体占地直径 0.6 |
| body_mass_kg | 80，供外力、载荷和接触反馈使用，进入车辆时质量贡献只计入一次 |
| eye_height_m | 站立 1.62，蹲姿 1.02，相对于脚底 |
| spawn_transform | 装载区提供 4 个独立出生点，按实际 1～4 人生成，人物体积不重叠 |
| life_state | Active、Recovering、Disconnected，按回合和连接状态维护 |
| recovery | 跌出场地时回到最近安全步行点，先清理抓取和座位关联 |
| ownership | 连接所有者、输入发送者和物理写入归属分开记录 |

生命值、伤害、饥饿、技能和长期成长列入 B 的产品设计待定清单。当前人物作业包的验收覆盖移动、身体占地、施力、乘车和恢复。

### 4.2 移动、跳跃与碰撞

| 字段 | 初始值或规则 |
|---|---|
| walk_speed_mps | 4.0 |
| sprint_speed_mps | 6.0 |
| crouch_speed_mps | 2.0 |
| carrying_speed_mps | 3.0，参与抓取时取当前姿态速度与此值的较小值 |
| ground_acceleration_mps2 | 16 |
| ground_braking_mps2 | 20 |
| gravity_mps2 | 9.8 向下 |
| jump_speed_mps | 空手保留 4.0 的暂定种子值，20 kg 木箱使用低于空手且大于零的起跳参数，具体值待测 |
| max_walkable_slope_deg | 45，实际碰撞能力随实现复核 |
| stand_clearance | 站起前检查完整站立体积，受阻时继续蹲姿并提示 |
| collision_feedback | 身体受到外力时仍可输入，外力位移与主动移动按同一更新结果合成 |
| vehicle_contact | 检查车身、门洞与地板碰撞，平稳行驶时支持后舱内正常移动，安全外部落点与舱内通行分开处理 |
| ground_rule | 空中重新按跳跃不会再次起跳，落地后可再次触发 |

携物跳跃按当前标准货物采用离散规则，具体高度和质量阈值均待测试。

| 状态 | 跳跃行为 | 验收重点 |
|---|---|---|
| 空手 | 正常地面起跳 | 建立空手高度基线 |
| 单人抓持 20 kg 木箱 | 保持抓取并允许较低高度起跳 | 人和木箱能够共同离地，高度低于空手 |
| 单人拖动 60 kg 圆桶 | 首轮先释放本人的抓取，再允许人物空手起跳 | 圆桶不继承人物跳跃速度或额外竖向冲量 |
| 操作 150 kg 重物 | 同样先释放本人抓取再空手起跳 | 重物不会被跳跃辅助带离地面 |
| 多人正在操作同物体 | 首轮沿用只释放跳跃者本人再空手起跳的简单提案 | 其他参与者继续生效，复杂协同跳跃留待后续 |

后舱内跳跃还受顶棚净空限制，20 kg 可跳不代表能穿过顶棚。坐在座位时按该座位输入上下文处理。平稳行驶时人物相对于后舱地板保持基本活动能力，急刹、急转、碰撞和剧烈颠簸可以影响稳定；具体跌倒或布娃娃机制仍为产品待定项。

### 4.4 混合抓取规则

稳定抱持条件为货物质量不超过当前有效参与者总支持质量，且目标未固定、抓取距离有效。其余可抓货物使用物理拖拽。两名玩家加入 60 kg 圆桶时可以进入合作抱持；150 kg 重物同时验证单人慢速推拖与双人效率提升。标准货物的搬运、上车和卸货必须有单人可完成路径，原受力与摩擦初值据此复核。

每位参与者的抓取点都通过有上限的辅助力朝自己的目标移动。物体与环境、车辆和其他货物持续碰撞。参与者方向不同会改变合力和力矩。稳定抱持使用连续辅助，位置与旋转的最终结果由物理状态产生。

一人加入或退出时重新计算承载模式，连续调整辅助强度。抓取点超距、对象销毁、玩家断线、回合重置和进入座位时清理该玩家的关联。进入座位前需要先松开货物，失败提示写入 HUD。

### 4.5 人物动画与反馈

原有 8 个循环动作 idle、walk、run、crouch_idle、crouch_walk、carry_idle、carry_walk、seated，以及 grab、release 两个片段继续作为既有清单。轻箱跳跃用占位姿态或现有动作混合验证人物与货物共同离地，位移由控制器驱动，新增精细动画不作为本轮交付要求。

本地第一人称隐藏会遮挡镜头的头部表面，保留合适的手臂或占位交互表现。其他玩家始终能观察角色朝向和搬运状态。进入驾驶上下文后，本地可观察完整角色或驾驶占位表现。

### 6.4 定速巡航

| 操作或条件 | 行为 |
|---|---|
| 达到希望保持的前进速度后按 C | 记录当前速度为目标，开启巡航，低速稳定运输是必要验证工况 |
| 开启后松开 W | 持续尝试维持目标速度 |
| 巡航中按 W | 不增加油门加速，目标速度保持原记录值 |
| 巡航中 A/D | 玩家继续控制方向 |
| 再按 C | 关闭巡航并恢复手动驾驶，松开油门时自然滑行 |
| 按 S | 同次输入立即取消巡航，并执行制动，低速倒车按原规则 |
| 按 Space | 同次输入立即取消巡航，并执行手刹 |
| 载荷、坡度和路面变化 | 实际速度可以偏离目标，允许适度自动制动帮助维持 |
| 驾驶位失效、断线或回合重置 | 清理巡航开启与目标状态，沿用原安全制动和生命周期处理 |

巡航只管理速度，转向由玩家完成。具体控制算法、自动制动力大小、最低可用速度阈值和复杂故障退出留待后续，记录试验值时标为暂定。

## 9. 多人共同作用与状态一致

### 9.1 同一个对象允许多人施加影响

每名玩家有独立参与记录，记录 player_id、局部抓取点、世界目标、有效输入序号和每人受力上限。一次有效抓取追加参与者，第一名参与者的关系继续保留。

同一物理更新内，把所有有效参与者的作用汇总到同一个刚体。

合力为所有有效力之和。合力矩为各作用点相对重心位置与对应力的叉积之和。每人的力先独立限幅，物体自身的接触、重力、固定和车厢碰撞继续参与计算。

同向拉动、反向牵制、不同抓点转动、一人退出、司机驾驶加同伴推动都作为独立验收场景。参与资格与物理状态写入归属分别处理。

### 9.2 一致性的具体含义

抓取参与者、固定关系、座位占用、交付结果、回合编号在各端采用同一确认版本。多人输入进入一套可追踪的物理结果，并向各端传播姿态与速度。

网络呈现允许插值延迟，采用同一状态时间点检查结果。静止物体收敛后初始容差为位置 0.05 m、角度 2 deg，离散状态必须一致。该容差和收敛窗口由 B 在网络标定记录中调整。

### 9.3 网络技术基线的状态

B 的首轮技术提案采用一个权威物理端汇总玩家操作，其他端提交输入并展示状态。房主或独立服务端、传输库与预测方案仍为技术评审项。此提案用于约束共享对象写入、命令去重和多参与者数据模型，用户确认后转为实施基线。

正式会话上限为 4，按 1、2、3、4 名实际玩家分别验收核心流程。原本地双进程案例保留为基础协作测试，再覆盖三人和四人接入及状态一致性。50 ms 和 100 ms 延迟仍为原网络测试条件初稿，具体实施分批推进，文档中的双人案例不限定正式人数。

| 文档线 | B02 API、B05/B06 功能单及素材清单 | 接入说明、配置位置、实际代码映射和变更说明 | 功能交付说明，与采用的 B 文档版本对应 |
| 实践线 | 完整功能范围和依赖接口 | 可运行功能、素材接入、演示和修复 | D 人物作业包或 E 载货运输包 |
| CI测试线 | 验收场景、断言和标定判据 | 编译、启动、逻辑、双端和回归检查的实际记录 | 本地命令、CI 入口、日志、结果和提交标识 |
| 审查线 | 审查清单、集成批次、接口和玩法验收 | 交叉审查、问题修复和复核结果 | D/E 技术互审，B 统一接收验收 |

五条线在每个可运行增量中同步推进。策划和文档输入由 B 维护，成员的实现反馈进入 B 的统一版本。D、E 的 CI 和技术审查各自覆盖已认领功能，共享入口由 B 指定一名本轮维护人。

B 的初稿指定 D 建立 C# 编译和基础会话检查入口，E 将物理、交付和场景检查接入同一入口。技术方案和实际仓库结构确认后，B 发布最终文件映射。

| GB-T24 | 巡航中分别按 S、Space，改变载重、坡度和路面 | 同次输入取消巡航并制动或手刹，允许适度自动制动，实际速度可偏离目标 | E |
| GB-T25 | 空手、抱 20 kg 木箱、拖 60 kg 圆桶、操作 150 kg 重物分别跳跃 | 空手正常、轻箱较低且共同离地，重货按简单规则先松手，人物能跳但货物不获跳跃冲量 | D/E |
